# [web-tour-360-and-facility-booking-telkom-corpu]

## Description

A web-based interactive virtual tour that allows users to explore a location in a 360-degree photo format directly through their browser.
This web tour is a representation of the [facilitycorpu.id](https://facilitycorpu.id/) website, developed to provide a more engaging and value-added experience. Through this tour, users can view detailed information about the facilities before making a booking.

---

## Key Features

1. **Get Data From Strapi**: Get data from strapi using GraphQL API methode. 
2. **Asset Visualization**: Display assets such as 360° background images, thumbnail photos, description texts, and gallery images fetched from the database.
3. **Hotspot Handler**: A component with button-like functionality that allows users to navigate between locations and view relevant information. 
4. **Navigation**: Enables users to move freely between different locations within the virtual tour.
5. **Camera Controller**: Manages the user’s point of view, allowing pan and tilt movements via mouse input or hand scroll on mobile devices.
6. **Canvas Manager**: Manages panels and UI elements displayed on the canvas, such as location maps, photo galleries, facility descriptions, and facility categories.
7. **Link Button**: Provides functionality to open the booking form page directly from the virtual tour interface.
